# CRM Status Updater - TicTac

תוסף ל-Chrome (Manifest V3) שמעדכן אוטומטית סטטוסים של לקוחות במערכת ה-CRM **TicTac**
(`tictac.moked-crm.co.il`) על בסיס דוח אקסל.

במקום לעדכן ידנית מאות לקוחות אחד-אחד, מעלים קובץ אקסל ("דוח מובייל"), והתוסף עובר
אוטומטית על כל הלקוחות בכל העמודים ומעדכן את הסטטוס שלהם.

## איך זה עובד

1. **העלאת אקסל** ([popup.html](popup.html) + [popup.js](popup.js))
   לוחצים על אייקון התוסף ומעלים קובץ אקסל. הקוד:
   - קורא את הקובץ עם ספריית `xlsx`.
   - מחפש לשונית מתאימה לפי שם (לפי סדר עדיפות: "חיבורים קווים" → "אקטובים מפורט" → "מפורט").
   - מזהה אוטומטית את עמודת **"קוד לקוח"**.
   - אוסף את כל קודי הלקוח לרשימה.

2. **הפעלת העדכון** ([runner.js](runner.js))
   הקוד מוזרק לדף ה-CRM ועובר על כל שורה בטבלה:
   - מחלץ את קוד הלקוח מהשורה.
   - אם הקוד נמצא ברשימת האקסל → מעדכן את הסטטוס.
   - אם הלקוח לא בדוח → מדלג.
   - ללקוח עם כמה קווים בסטטוסים שונים ("mixed") — פותח מודאל ומעדכן כל שורה בנפרד.

3. **מעבר בין עמודים אוטומטי** ([background.js](background.js))
   בסיום עמוד, התוסף מנווט לעמוד הבא (פרמטר `pg` ב-URL). ה-Service Worker מזהה את
   טעינת העמוד החדש ומזריק מחדש את ה-runner כדי להמשיך, תוך שמירת התקדמות
   ב-`chrome.storage.local`.

4. **תצוגת התקדמות**
   לוח צף על הדף (RTL) שמראה כמה **עודכנו**, כמה **לא נמצאו**, כמה **נבדקו**,
   עם לוג חי וכפתור **עצור**.

## התקנה (מצב מפתח)

1. פותחים את `chrome://extensions`.
2. מפעילים **Developer mode**.
3. לוחצים **Load unpacked** ובוחרים את תיקיית הפרויקט.

## מבנה הקבצים

| קובץ | תפקיד |
|------|--------|
| `manifest.json` | הגדרות התוסף (Manifest V3) |
| `popup.html` / `popup.js` | ממשק המשתמש וקריאת קובץ האקסל |
| `runner.js` | הלוגיקה שרצה בתוך דף ה-CRM ומעדכנת סטטוסים |
| `background.js` | Service Worker — המשך אוטומטי בין עמודים |
| `content.js` | גשר בין דף ה-CRM ל-Chrome APIs |
| `xlsx.full.min.js` | ספריית SheetJS לקריאת קבצי אקסל |
